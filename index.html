Privacy Policy — Spacebar Preview

Last updated: October 30, 2026

Spacebar Preview ("the app") is a Windows system tray utility that shows a quick preview of the file selected in File Explorer or on the desktop when you press the Space key.

Data Collection

The app does not collect, store, transmit, or share any personal data or usage information. It does not use analytics, telemetry, advertising SDKs, or accounts, and it does not send any data of its own over the network.

Keyboard Input

To open the preview with the Space key, the app watches key presses while it is running. It only reacts to Space, Esc, Enter and the arrow keys when File Explorer, the desktop or the preview window is active. Key presses are examined in memory as they happen and are never recorded, logged, stored or transmitted. To avoid opening a preview while you type a file name in File Explorer, the app keeps only the time of the last key press in memory, not the key itself.

Files and Folders

When you ask for a preview, the app reads which items are selected in File Explorer or on the desktop, and reads the selected file or folder from your disk to display it. Files are opened read-only and are never modified, uploaded or copied anywhere outside your computer. Some formats are displayed using preview handlers that are already installed in Windows (for example, by Microsoft Office); those components run on your device and are provided by their respective publishers.

Web Content in Previews

PDF, video, audio, Markdown, HTML and Word documents are displayed with Microsoft Edge WebView2, a component of Windows. Scripts in previewed HTML, Markdown and office documents are disabled, and links you click open in your default web browser. If a previewed HTML or Markdown file itself refers to online content (for example, an image hosted on a website), WebView2 may load that content from the internet, just as a web browser would when opening the same file. The app adds nothing to such requests. WebView2 is provided by Microsoft and is covered by the Microsoft Privacy Statement.

Data Stored on Your Device

The app stores only the following, locally on your device:

  • Settings: the selected theme and the preview window size.
  • The WebView2 cache used to display previews.
  • Temporary files for previews of large documents, which are deleted automatically.

All of this is removed when you uninstall the app.

Permissions

The app runs with full-trust (Win32) permissions because it needs to receive key presses, read the selection in File Explorer, use the system tray and Windows preview handlers, which are not available to sandboxed applications. These permissions are used exclusively for the functionality described above.

Third Parties

The app does not integrate with, or send data to, any third-party service.
